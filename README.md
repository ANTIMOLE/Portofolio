## Development

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Deployment

The project uses GitHub Pages for deployment through GitHub Actions.

The deployment workflow is located at:

```text
.github/workflows/deploy.yml
```
